Privacy policy

assistant-hub · last updated 5 October 2026

Who uses this app

assistant-hub is a personal tool operated by its owner (damienmiheev@gmail.com) for his own Google account only. No one else is invited or able to use it.

What data it accesses

With the owner's consent, it reads messages in the owner's Gmail (gmail.readonly) and creates drafts (gmail.compose). It does not send or delete email.

How data is used

  • To produce summaries, reminders and draft replies for the owner.
  • Message content is processed by an AI model (Anthropic Claude) to generate those summaries.
  • Short notes (for example, a list of bills and due dates) are stored on the owner's private server.

Sharing

Data is not sold, shared with third parties, or used for advertising. It is shared only with the services needed to run the tool: Google (Gmail API), Anthropic (AI processing) and Telegram (delivering messages to the owner).

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Stored notes are deleted on request or when the tool is retired.
